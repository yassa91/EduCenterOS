# Skills الخاصة بمشروع EduCenterOS

هذا المجلد جاهز لإضافة ملفات الـskills الخاصة بالمشروع عند تجهيزها.
كل skill لها مجلد مستقل يحتوي على ملف باسم `SKILL.md`:

```text
.agents/skills/
└── skill-name/
    └── SKILL.md
```

## تجهيز ملف الـskill

اختر اسمًا قصيرًا بحروف إنجليزية صغيرة وأرقام وشرطات، واجعل اسم المجلد
مطابقًا لقيمة `name`. يبدأ الملف بالصيغة التالية، مع استبدال المثال بالمحتوى الفعلي:

```markdown
---
name: skill-name
description: وصف محدد لما تفعله الـskill ومتى تستخدمها.
---

# عنوان الـskill

التعليمات والخطوات الخاصة بالمهمة.
```

إذا كانت الـskill تأتي بملفات مساعدة، احتفظ بها داخل مجلدها وبالمسارات التي
يشير إليها `SKILL.md`، مثل `references/` أو `scripts/` أو `assets/` عند الحاجة.

Codex يكتشف الـskills الموجودة هنا ويختار المناسب منها حسب وصفها. ويمكن طلب
استخدام skill معينة بذكر `$skill-name` في الرسالة. إذا لم تظهر بعد إضافتها، أعد
تشغيل Codex.

تظل تعليمات المشروع العامة في [AGENTS.md](../../AGENTS.md).
هذا الملف دليل تجهيز؛ تعليمات كل skill موجودة في ملفها المستقل.

مهارة التنسيق الخاصة بالمشروع هي
[`educenteros-formatting`](educenteros-formatting/SKILL.md).
هي المرجع الوحيد لقواعد التنسيق وإعداداته وتنفيذ أداته؛ الملفات الأخرى تشير لها فقط.
جزء التنسيق في `clean-code` معدّل محليًا ليشير لها؛ حافظ على هذا التعديل عند تحديث المهارة.

المرجع: [توثيق OpenAI الرسمي للـskills](https://learn.chatgpt.com/docs/build-skills).
