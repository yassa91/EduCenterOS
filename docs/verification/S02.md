## Limits and remaining project dependencies

The API listens only on loopback in Development/Testing. Numeric policy is a reviewed local baseline, not production policy. IP budgets are process-local bounded framework buckets; durable target budgets survive restart. Production needs T39 hosting/forwarding/secrets delivery, real SMS delivery semantics and coordinated multi-instance abuse protection. The private repository plan does not support branch protection; exact-head acceptance, self-review and CI gates were enforced procedurally under T40. No independent reviewer approval is claimed.
